# WandEnhancer — Windows EXE Builds

Unofficial prebuilt Windows executables for
[k1tbyte/Wand-Enhancer](https://github.com/k1tbyte/Wand-Enhancer).

This repository exists for users who want to use WandEnhancer without
building it themselves.

> **This is NOT the official WandEnhancer repository.**
> All development and source code belong to the upstream project.

---

## Downloads

Go to the **[Releases](../../releases)** page to download the latest build.

### Which EXE should I download?

| File | What it does |
|---|---|
| `WandEnhancer.exe` | Standard build. No startup update check. |
| `WandEnhancer-UpdateNotifications.exe` | Standard build + checks for newer releases when Wand starts. |

**Not sure which one to pick?**

Download **`WandEnhancer-UpdateNotifications.exe`**.

It only checks for a newer release and notifies you. It does **not**
automatically download or install updates.

---

## Security / Trust

These executables are **unsigned**.

Windows Defender or SmartScreen may therefore display a warning because
the executable is unsigned and not widely recognized.

Every release identifies the upstream source commit used to build it.

You should only use builds you trust.
